API Reference

Single patient

seminal.azoospermia_fsh(fsh, clip=True)[source]

Probability of azoospermia from serum FSH alone (quadratic model).

Parameters:

  • fsh (float or array-like) – Serum follicle-stimulating hormone in IU/L.

  • clip (bool, default True) – Clip the result to [0, 1]. The published quadratic exceeds 100% above roughly 30 IU/L and is unbounded; the paper’s own validation tables carry unclipped values above 1. Set clip=False to reproduce that behaviour exactly.

Returns:

Probability between 0 and 1 (a fraction, not a percent).

Return type:

float or numpy.ndarray

Notes

The curve is U-shaped: 10.1% at undetectable FSH, a minimum of about 8.4% at FSH 3.6 IU/L, and 100% at about 29.9 IU/L.

Examples

>>> round(azoospermia_fsh(0), 3)
0.101
>>> round(azoospermia_fsh(20), 3)
0.439
seminal.azoospermia_lr(age, fsh, lh, testosterone, testis_volume, explain=False)[source]

Probability of azoospermia from the logistic regression model.

Parameters:

  • age (float) – Age in years.

  • fsh (float) – Serum FSH in IU/L.

  • lh (float) – Serum luteinizing hormone in IU/L.

  • testosterone (float) – Total testosterone in ng/dL. (Divide nmol/L by 0.03467 to convert.)

  • testis_volume (float) – Mean of left and right testis volume in cm^3 (mL), as estimated by Prader orchidometer in the development cohort.

  • explain (bool, default False) – Return a breakdown instead of just the probability.

Returns:

Probability between 0 and 1. With explain=True, a dict with risk, intercept, linear_predictor (log-odds) and contributions (each predictor’s log-odds term, largest first).

Return type:

float or dict

Notes

The paper prints the model form as 1/exp[-(b0 + bi*Xi)], which is a typesetting error (it would exceed 1). The standard logistic form 1/(1 + exp(-(b0 + sum(bi*Xi)))) is used here.

Examples

>>> round(azoospermia_lr(age=36, fsh=5.7, lh=4.5, testosterone=429,
...                      testis_volume=15), 3)
0.086

seminal.add_azoospermia_risk_cols(df, age_col='age', fsh_col='fsh', lh_col='lh', testosterone_col='testosterone', testis_volume_col='testis_volume', lr_col='azoo_lr', fsh_model_col='azoo_fsh', copy=True)[source]

Add both azoospermia probabilities to every row of a DataFrame.

Parameters:

  • df (pandas.DataFrame) – One row per semen analysis / hormone panel.

  • age_col (str) – Column names for the five logistic-model inputs. Only fsh_col is needed for the FSH-only model.

  • fsh_col (str) – Column names for the five logistic-model inputs. Only fsh_col is needed for the FSH-only model.

  • lh_col (str) – Column names for the five logistic-model inputs. Only fsh_col is needed for the FSH-only model.

  • testosterone_col (str) – Column names for the five logistic-model inputs. Only fsh_col is needed for the FSH-only model.

  • testis_volume_col (str) – Column names for the five logistic-model inputs. Only fsh_col is needed for the FSH-only model.

  • lr_col (str, default "azoo_lr") – Name of the logistic regression probability column.

  • fsh_model_col (str, default "azoo_fsh") – Name of the FSH-only quadratic probability column.

  • copy (bool, default True) – Work on a copy and leave df unchanged.

Returns:

df (or a copy) with the two probability columns added. A row with any logistic-model input missing gets NaN in lr_col; the FSH-only column needs only FSH.

Return type:

pandas.DataFrame

Constants

seminal.azoospermia.LR_COEFS

Table 3 coefficients on the log-odds scale: intercept, age, fsh, lh, testosterone, testis_volume.

seminal.azoospermia.FSH_QUAD

Fig. 1 quadratic in percent: a (FSH²), b (FSH), c (constant).

seminal.azoospermia.REFERENCE_RANGES

Reference limits quoted in the paper for FSH, LH, total testosterone and mean testis volume. Informational only; the models do not threshold on them.
